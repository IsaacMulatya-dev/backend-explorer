Backend Explorer

Overview
An Express and Node.js backend setup demonstrating secure authentication, structured logging, centralized error handling and database integrations with PostgreSQL and MongoDB.

Technologies Used
- Node.js
- Express.js
- PostgreSQL
- MongoDB and Mongoose
- JSON Web Tokens (JWT)
- Winston Logger and Morgan

Key Features
- Centralized error handling middleware
- JWT authentication and route protection
- PostgreSQL relational queries and schema management
- Winston logger integration for request tracing and error logs

Setup Instructions

git clone https://github.com/IsaacMulatya-dev/backend-explorer.git
cd backend-explorer
npm install
npm start
